# Canonical Project and Attribution

## Canonical upstream

The canonical NV Broadcast source repository is:

https://github.com/Hkshoonya/nvidia-broadcast-linux

NV Broadcast was originally created by **DocZeus**, whose GitHub account is
[@Hkshoonya](https://github.com/Hkshoonya). The GitHub username `doczeus`
belongs to a different person and must not be used as the project author's
profile link.

Official source releases are published through the canonical repository's
[Releases](https://github.com/Hkshoonya/nvidia-broadcast-linux/releases) page.
Store packages should link back to the same canonical repository.

## Forks and mirrors

Forks, mirrors, and derivative versions are part of open-source development and
are permitted when they comply with the project license. To prevent users from
mistaking a downstream version for the canonical project, downstream
maintainers should:

- identify the repository as a fork, mirror, or derivative near the top of its
  README;
- name the original project and DocZeus as its creator;
- link to the canonical repository;
- preserve the LICENSE, copyright notices, source headers, metadata, and
  in-application attribution required by the license; and
- distinguish downstream releases and support channels from official ones.

Using the same repository or application name does not by itself prove that
code was copied improperly. Commit ancestry, source similarity, retained
license notices, release packaging, and claims of authorship must be reviewed
before contacting or reporting another project.

## Suspected violations

Before making a copyright or platform report:

1. Preserve links, commit identifiers, screenshots, and exact copied files.
2. Check whether the repository is a GitHub fork or a license-compliant mirror.
3. Compare the source and history rather than relying only on similar features
   or naming.
4. Contact the maintainer first with a specific, professional correction
   request when doing so is appropriate.
5. Use GitHub's copyright or trademark process only for a supported claim and
   after obtaining qualified legal advice where needed.
