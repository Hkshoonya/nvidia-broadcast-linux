# SPDX schema attribution

`schema.json` is an unchanged copy of `schemas/spdx-schema.json` from the SPDX
Specification project, tag `v2.3`, commit
`aadf3b0b8dbbabdb4d880b0fc714255fea436ff7`.
Copyright the SPDX Specification contributors; distributed under
Creative Commons Attribution 3.0 Unported. The unchanged upstream `LICENSE`
is retained alongside it. `UPSTREAM.json` records exact source URLs and hashes.

Source: https://github.com/spdx/spdx-spec/tree/aadf3b0b8dbbabdb4d880b0fc714255fea436ff7

This schema is a test fixture only. No external schema reference is fetched
during validation, and the inventory tool does not depend on a schema validator
at runtime.
